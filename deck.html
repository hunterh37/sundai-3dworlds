Scene, camera, loop

// 1. setup
const scene = new THREE.Scene();
const camera = new THREE.PerspectiveCamera(75, w/h, .1, 100);
const renderer = new THREE.WebGLRenderer({ antialias: true });
document.body.appendChild(renderer.domElement);
SETUPA scene holds things. A camera looks at them. A renderer draws to a canvas.
// 2. mesh
const cube = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshNormalMaterial());
scene.add(cube);
MESHShape plus surface. Every visible object is one.
// 3. loop
renderer.setAnimationLoop((t) => {
  cube.rotation.y = t / 1000;
  renderer.render(scene, camera);
});
LOOPEvery frame: change state, then render.

Vision loop09 / 16

Photo to Three.js

01 REFERENCEOne photo. Note camera angle, light, materials.
02 BUILDModel it in Three.js. Same camera, same backdrop.
03 SCREENSHOTHeadless Chrome renders the scene to PNG.
04 SCOREClaude views both, scores 0 to 10, lists the top 3 gaps.
05 GATEFix the gaps, repeat until score ≥ 7.0.
Recreate photo.jpg in Three.js. Screenshot your render, compare it side by side with the photo, score realism 0-10, fix the top 3 gaps. Loop until 7.0+. Never grade without viewing both images.
