# Resources

## Three.js toolkit

From https://github.com/AxiomeCG/awesome-threejs

- [Poly Haven](https://polyhaven.com): CC0 models, HDRIs, textures
- [ambientCG](https://ambientcg.com): CC0 PBR materials
- [Matcaps](https://github.com/nidorx/matcaps): 600+ matcap textures
- [drei](https://drei.docs.pmnd.rs): R3F helpers, ready to use
- [Rapier](https://rapier.rs): Fast WASM physics
- [three-mesh-bvh](https://github.com/gkjohnson): Fast raycasts + collisions
- [LYGIA](https://lygia.xyz): Drop-in shader functions
- [Book of Shaders](https://thebookofshaders.com): Learn GLSL, free
- [Spline](https://spline.design): 3D design, export to web
- [three.js examples](https://threejs.org/examples): Copy a working start
