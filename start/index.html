Getting started

From zero to a running Three.js world in ten minutes. Paste the system prompt into your agent, pick an example, iterate.

1. Setup

  1. Install Node 20+ (nodejs.org).
  2. Open a coding agent: Claude Code, Cursor, or claude.ai.
  3. Run:
npm create vite@latest my-world -- --template vanilla
cd my-world && npm i three && npm run dev

Open the localhost URL Vite prints. Edits to main.js reload live.

2. System prompt

Paste this first, before any idea. In Claude Code save it as CLAUDE.md in the project root; in Cursor as .cursorrules.

You are building a Three.js world for a one-day hackathon. Ship something that runs, then make it beautiful.

Stack
- Vite vanilla template, ES modules, `import * as THREE from 'three'`.
- Addons from 'three/addons/...' (OrbitControls, GLTFLoader, EffectComposer, UnrealBloomPass).
- Physics: cannon-es or @dimforge/rapier3d-compat. Only if the idea needs it.
- No React, no TypeScript, no build config changes unless asked.

Rules
- Every reply leaves the app running. Never leave a black screen.
- Start with: scene, camera, renderer.setAnimationLoop, resize handler, setPixelRatio(min(devicePixelRatio, 2)).
- Keep main.js under 300 lines. Split into world.js, controls.js, fx.js when it grows.
- Primitives and procedural geometry first. No external models until the core loop works.
- Lighting: HemisphereLight + one DirectionalLight with shadows. Set renderer.outputColorSpace = SRGBColorSpace and ACESFilmic tone mapping.
- Performance: InstancedMesh for anything over 100 copies, BufferGeometry for particles, dispose what you remove. Target 60 fps on a laptop.
- Input: mouse/touch and keyboard both work. Show a one-line hint overlay of the controls.
- When something breaks, read the browser console error first and fix the cause.

Workflow
1. Restate the idea in one sentence and list the 3 steps you will build.
2. Build step 1 as a minimal running scene. Tell me what to look at.
3. Add the interaction. Then the look (color palette, fog, post FX).
4. After each step, suggest one concrete upgrade I can say yes to.

Style default (override if I say otherwise)
- Limited palette: 2 to 3 colors plus black or off-white.
- Fog matching the background color. Soft shadows. Slow camera easing.
- One signature effect (bloom, dither, toon, halftone) instead of many.

3. Examples

Live builds and prompts to remix. Paste one after the system prompt.

Pop-up book · live

Three.js portfolio as a pop-up book. One app per spread, cut-paper layers stand up as the page turns. Two-ink risograph print, halftone, soft shadows. Drag to turn, tap an icon to open it.

Chladni plate · live

Chladni plate in Three.js. 46,000 sand grains jitter by local plate amplitude and settle on the nodal lines. Drag to tune the mode, play the tone. Low-res render, 1-bit Bayer dither.

Drivable world · reference

Build a Three.js scene with a low-poly car on a flat plane. WASD drives it, cannon-es for physics, camera follows from above at 45°. Black ground, white objects.

Tiny planet · reference

Make a small sphere planet in Three.js. A character walks on its surface with gravity toward the center. Camera orbits behind. Add toon shading and soft fog.

Particle galaxy · reference

Build a spiral galaxy of 50,000 particles in Three.js with a ShaderMaterial. Three arms, hot pink core fading to violet at the edges, slow rotation, additive blending, OrbitControls.

Data globe · reference

Render a wireframe globe in Three.js. Load a JSON of cities with lat and lon, draw them as points, connect pairs with animated arcs. OrbitControls with damping.

4. Iterate

Follow-up prompts that work on any scene:

Add post-processing: UnrealBloomPass on emissive parts only, subtle film grain, vignette.
Make it feel alive: idle animation on every object, camera breathes slightly, ambient particles drift.
It runs slow. Profile draw calls with renderer.info, merge or instance what repeats, cap pixel ratio at 1.5.
Add a title overlay, a mute button, and a share link. Then deploy to GitHub Pages with vite build.

5. Ship

npm run build
npx vercel deploy dist     # or drag dist/ onto app.netlify.com/drop

Set base: './' in vite.config.js for GitHub Pages subpaths.
